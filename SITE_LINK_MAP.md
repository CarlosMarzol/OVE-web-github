# Mapa de enlaces del sitio OVE

## Portada nueva

- `/` -> portada institucional nueva en `index.html`.
- Desde subpaginas, cualquier enlace a `/` debe recargar la portada nueva y no renderizar la home antigua de `app.js`.

## Navegacion principal

- `/indicadores` -> explorador de indicadores.
- `/publicaciones` -> repositorio de publicaciones.
- `/datos` -> banco de datos.
- `/metodologia` -> metodologia y criterios.
- `/manifiesto` -> manifiesto institucional.
- `/nosotros` -> informacion institucional.
- `/contacto` -> contacto y boletin.

## Enlaces destacados de la portada

- `/indicadores` -> boton principal "Consultar indicadores".
- `/datos` -> boton secundario "Explorar datos y fuentes".
- `/datos/economia/pib-precios-constantes-moneda-nacional` -> panel "Indicador destacado".
- `/nota-lanzamiento` -> tarjeta de prelanzamiento institucional.
- `/publicaciones` -> tarjeta de primer informe economico.

## Fuentes enlazadas desde la portada

- `/datos/bcv` -> Banco Central de Venezuela.
- `/datos/banco-mundial` -> Banco Mundial WDI.
- `/datos/fmi` -> FMI WEO.
- `/datos/oit` -> OIT ILOSTAT.
- `/datos/fred` -> FRED.
- `/datos/ine` -> INE Venezuela.
- `/datos/cepal` -> CEPALSTAT.
- `/datos/unctad` -> UNCTADstat.
